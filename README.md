## การนำไปใช้งาน (Hosting)

เป็นเว็บ static ล้วน ไม่ต้องมี backend เปิดใช้ได้ทันทีหลายวิธี:

- **เปิดในเครื่อง:** ดับเบิลคลิก `index.html` (ลิงก์ระหว่างหน้าเป็น relative จึงทำงานได้เลย)
- **GitHub Pages:** อัปโหลดทั้งโฟลเดอร์เข้า repository แล้วเปิด Settings → Pages → เลือก branch
- **Netlify / Vercel / Cloudflare Pages:** ลากโฟลเดอร์วาง (drag & drop) หรือเชื่อม repository
- **เว็บโฮสต์ทั่วไป:** อัปโหลดทั้งโฟลเดอร์ผ่าน FTP

## คุณสมบัติ

- Responsive (มือถือ–เดสก์ท็อป) · เมนูแฮมเบอร์เกอร์บนจอเล็ก

- พิมพ์ได้ · โครงสร้าง semantic · โฟกัสคีย์บอร์ด
